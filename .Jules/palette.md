## 2025-05-22 - Tooltips for Technical Acronyms
**Learning:** For specialized forms using industry standards (like AAMVA), providing localized tooltips for technical acronyms significantly improves accessibility for non-expert users without cluttering the UI. In Streamlit, the `help` parameter is an efficient way to achieve this as it also serves as an accessible label.
**Action:** Always check for technical shorthand in UI labels and provide explanatory tooltips.
