## 2025-05-15 - Improving Technical Field Clarity
**Learning:** In technical applications like AAMVA data synthesis, users often encounter cryptic acronyms (DCG, DAC, etc.) that hinder usability. Using Streamlit's native `help` parameter is an effective, non-intrusive way to provide immediate context without cluttering the UI.
**Action:** Always provide descriptive tooltips for industry-specific codes and ensure form controls have valid accessibility labels even when visual labels are collapsed.
