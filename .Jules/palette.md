# Palette's Journal

## 2026-07-12 - Technical Clarity via Tooltips
**Learning:** Users in technical domains (like AAMVA standards) often struggle with cryptic three-letter acronyms (DCG, DAQ, etc.). Providing immediate, localized context through native tooltips significantly reduces cognitive load without cluttering the "Pro" UI.
**Action:** Use Streamlit's `help` parameter to define technical fields, ensuring tooltips are available in the user's selected language.
