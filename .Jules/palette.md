## 2026-11-02 - Accessible Collapsed Labels and Responsive Column Budgeting in Streamlit
**Learning:** In Streamlit, passing an empty label `""` to an input widget like `st.selectbox` raises accessibility warnings and prevents assistive screen readers from inferring element purpose. Using a meaningful localized label with `label_visibility="collapsed"` supplies the necessary ARIA accessible name while preserving a clean UI. Additionally, tight header column allocations (e.g., `[8, 1, 1]`) cause dropdown text like "EN" to truncate to "E"; allocating at least `1.8` flex ratio ensures language selectors have adequate padding without wrapping.
**Action:** Always provide descriptive labels even when using `label_visibility="collapsed"`, and allocate sufficient column ratio (>= 1.5) for select widgets in horizontal header bars.
