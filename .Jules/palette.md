## 2026-07-27 - Streamlit Language Selector and Theme Accessibility
**Learning:** Collapsed labels on Streamlit selectboxes using `label_visibility="collapsed"` still generate a valid `aria-label` for screen reader accessibility, provided a non-empty string is supplied to the `label` parameter. Furthermore, emoji-only icon buttons lack accessible descriptions unless custom tooltips are supplied via the `help` parameter, and adjusting column proportions from `[8, 1, 1]` to `[7, 1.2, 1.8]` prevents clipping of language drop-downs on standard viewports.
**Action:** Always provide descriptive labels even when using `label_visibility="collapsed"`, set custom tooltips with the `help` parameter on icon-only buttons, and allocate sufficient column weights (e.g., at least 1.8 units for language selectors) to ensure text and arrows are not clipped.
