## 2025-05-15 - Enhancing technical field clarity with tooltips
**Learning:** In applications dealing with technical standards like AAMVA, using cryptic acronyms (DCG, DAQ, etc.) can be confusing. Streamlit's 'help' parameter provides a native way to add tooltips that improve both UX and accessibility without cluttering the UI.
**Action:** Use the 'help' parameter in Streamlit input components to provide definitions for technical codes.
