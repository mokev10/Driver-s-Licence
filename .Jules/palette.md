## 2025-05-15 - Enhancing specialized UIs with technical tooltips
**Learning:** In specialized tools like AAMVA barcode generators, users often encounter cryptic industry-standard acronyms (DCG, DAC, etc.). Providing immediate, localized context through tooltips significantly reduces cognitive load and prevents errors without cluttering the professional "Liquid Glass" aesthetic.
**Action:** Always prioritize adding the `help` parameter to technical input fields and cryptic UI controls to ensure the application remains accessible to both experts and newcomers.
