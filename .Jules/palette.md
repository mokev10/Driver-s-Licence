## 2026-07-31 - [Streamlit Selectbox Label Accessibility]
**Learning:** In Streamlit applications, utilizing `label_visibility="collapsed"` is common to create a clean, minimalist UI without displaying verbose text labels. However, visually collapsing a label does not mean omitting it. For screen readers and assistive technologies to associate an accessible name (ARIA label) with the form input, a valid and localized descriptive text label must still be supplied to the selectbox. Omitting the label entirely or passing an empty string ("") leads to form elements with missing accessible names.
**Action:** Always provide a valid, descriptive, and localized label text to `st.selectbox` or `st.text_input` even when `label_visibility` is set to "collapsed" or "hidden". This ensures high accessibility standards without cluttering the visual interface.
