## 2025-05-15 - Enhancing Cryptic Acronyms with Tooltips
**Learning:** Technical users often forget or never knew standard acronyms (e.g., AAMVA codes like DCG, DAQ). Providing immediate, localized context via tooltips significantly reduces cognitive load without cluttering the UI.
**Action:** Use Streamlit's `help` parameter on all technical fields to provide plain-language explanations.
